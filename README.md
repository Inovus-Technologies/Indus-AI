# 🤖 Indus AI

> An experimental AI assistant built from scratch to explore transformer architectures, conversational AI, memory systems, and modern web technologies.

---

## 📖 Overview

Indus AI is a personal research and development project focused on understanding how modern AI assistants work internally rather than simply consuming pre-trained APIs.

The project combines a custom AI architecture, conversational memory, model training pipeline, and an interactive web interface into a single application.

This project is designed as a learning platform for building intelligent systems from the ground up.

---

# ✨ Features

- 🧠 Custom Transformer-based architecture
- 💬 Interactive AI chat interface
- 🗂️ Persistent conversation memory
- 📚 Knowledge management system
- 🎨 Modern responsive UI
- 🌙 Dark / Light theme
- ⚡ Fast interactive experience
- 🧩 Modular project structure
- 🔄 Training pipeline
- 💾 SQLite-based storage
